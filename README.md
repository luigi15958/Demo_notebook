# מחברת החונכות האישית

אפליקציה לליווי תהליך החונכות האישית בבית הספר הדמוקרטי הוד השרון — תיעוד, ניהול והחזקה מערכתית של התהליך המרכזי בבית הספר, ברוח חוברת החונכות ("מדריך לחונכ.ת").

## מסמכים

- [דף חזון](docs/VISION.md) — למה, למי, ומה האפליקציה עושה לאורך שנת הלימודים
- [ארכיטקטורה](docs/ARCHITECTURE.md) — עקרונות, סטאק, מודל נתונים, הרשאות, אבטחה, שלבי מימוש והכרעות

## האפליקציה (MVP)

קוד האפליקציה נמצא בתיקיית [`app/`](app) — React + TypeScript + Vite, עברית RTL.

### הרצה מקומית (מצב הדגמה)

```bash
cd app
npm install
npm run dev
```

ללא הגדרות נוספות האפליקציה רצה ב**מצב הדגמה**: הנתונים (דמויות בדויות) נשמרים ב-localStorage של הדפדפן בלבד, ואפשר להתנסות בכל הזרימות — תיעוד מפגשים, מטרות, יומן קשר וספריית החונכות.

### חיבור ל-Supabase (סביבת אמת)

1. יוצרים פרויקט ב-[Supabase](https://supabase.com) ומריצים את המיגרציה `supabase/migrations/0001_init.sql` (טבלאות + מדיניות Row-Level Security).
2. יוצרים משתמשי צוות ב-Supabase Auth ושורת פרופיל תואמת בטבלת `profiles`.
3. מגדירים בקובץ `app/.env.local`:

```
VITE_SUPABASE_URL=https://<project>.supabase.co
VITE_SUPABASE_ANON_KEY=<anon key>
```

עם המשתנים האלה האפליקציה עוברת אוטומטית ממצב הדגמה להתחברות אמיתית (אימייל + סיסמה), וההרשאות נאכפות בצד השרת: כל חונכ.ת רואה את החניכים שלה בלבד.

### תכולת ה-MVP

- **החניכים שלי** — רשימת חניכים עם התראה עדינה על פער מפגשים
- **כרטיס חניכ.ה** — סקירה ("לקראת המפגש הבא"), חוזקות, תיק היכרות
- **תיעוד מפגש** — לפי פורמט החוברת: נושאים, חוזקות ואתגרים, דרכי פעולה, תובנות, שיתוף; מוקד המפגש לפי איזון Being–Doing
- **מטרות** — בארבעת התחומים (לימודי, חברתי, אישי, רגשי) עם מעקב סטטוס
- **יומן קשר** — משולש התקשורת: הורים, מורים, יועצת, רכזת
- **ספריית החונכות** — תמצית ששת פרקי החוברת, זמינה תמיד

המשך הדרך (שלבים 2–4) מפורט ב[מסמך הארכיטקטורה](docs/ARCHITECTURE.md#8-שלבי-מימוש-מוצעים).
