# מחברת החונכות האישית

אפליקציה לליווי תהליך החונכות האישית בבית הספר הדמוקרטי הוד השרון — תיעוד, ניהול והחזקה מערכתית של התהליך המרכזי בבית הספר, ברוח חוברת החונכות ("מדריך לחונכ.ת").

## מסמכים

- [דף חזון](docs/VISION.md) — למה, למי, ומה האפליקציה עושה לאורך שנת הלימודים
- [ארכיטקטורה](docs/ARCHITECTURE.md) — עקרונות, סטאק, מודל נתונים, הרשאות, אבטחה ושלבי מימוש
